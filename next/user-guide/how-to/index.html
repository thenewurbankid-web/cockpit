Construct

How-to guides

Task-based guides for everyday work.

Task-based guides. Each one is short, uses real commands, and links to the deeper reference when you need it.

Every command accepts --dir <path> so you can run it from anywhere; it finds the nearest architecture.yml above that path and never touches anything outside the project.
