src/ast/jsxParse

AST package: strict JSX parsing on typescript-estree (the JSX edit/analysis family, #173).

AST, next. Source: src/ast/jsxParse.mjs.

Functions#

checkJsxReplacement()#

checkJsxReplacement(snippet): { ok: true; } | { error: string; kind: "parse"; ok: false; } | { kind: "shape"; ok: false; }

Defined in: src/ast/jsxParse.mjs:85

Check a replacement snippet that is to be spliced in place of one JSX node: it must parse on its own as a JSX expression, and be exactly one element or fragment. Returns {ok: true}, or {ok: false, kind: 'parse', error} (not valid JSX) / {ok: false, kind: 'shape'} (valid, but not a single JSX element/fragment).

Parameters#

snippet

string

Candidate replacement for one JSX node.

Returns#

{ ok: true; } | { error: string; kind: "parse"; ok: false; } | { kind: "shape"; ok: false; }

Whether the snippet is exactly one element or fragment.

Example#

checkJsxReplacement('<b>hi</b>'); // => { ok: true }
