assignTestIds()#

assignTestIds(machines): object

Defined in: src/engine/testAttributes.mjs:54

The data-testid for every user event of every machine in a feature. machines: extracted machines in a stable order. Returns { keys, testIds } where testIds[i] is a Map(event -> testid) for machine i and keys[i] is its machine key. An event name used by two or more machines is scoped <machine key>-<event> on all of them.
