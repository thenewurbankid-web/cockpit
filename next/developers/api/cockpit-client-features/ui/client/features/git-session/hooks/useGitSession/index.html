Variables#

POLL_MS#

const POLL_MS: 1500 = 1500

Defined in: ui/client/features/git-session/hooks/useGitSession.tsx:11

How often the Cockpit re-reads the session. The coalescing window closes on the SERVER's timer, so without a poll the indicator would go stale at exactly the moment a commit happens.

Functions#

useGitSession()#

useGitSession(): object

Defined in: ui/client/features/git-session/hooks/useGitSession.tsx:32

The commit-on-save session: current config, the branch, what is pending, and the one question this feature may ask (a dirty tree at session start). Polls rather than being told, because commits also happen on a timer, with no request in flight to attach a response to.
