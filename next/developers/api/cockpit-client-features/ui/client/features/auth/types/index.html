AuthSession#

AuthSession = object

Defined in: ui/client/features/auth/types.ts:20

Shape returned by ui/server's public GET /auth/session (see ui/server/src/auth.mjs) — the single source of truth for whether this Cockpit requires a login and whether this browser has one.

authRequired: false is the honest answer for an unauthenticated loopback run (the default for local development): there is no gate, and the Cockpit renders directly. It is never false when the server is bound off loopback — the server refuses to start in that combination.
