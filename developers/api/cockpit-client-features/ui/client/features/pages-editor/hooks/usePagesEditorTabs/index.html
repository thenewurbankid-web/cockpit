ui/client/features/pages-editor/hooks/usePagesEditorTabs

usePagesEditorTabs()#

usePagesEditorTabs(e): void

Defined in: ui/client/features/pages-editor/hooks/usePagesEditorTabs.tsx:17

Puts the Pages Editor's panels into the shell (slot registry): the page/feature tree in the Browser pane and Inspector / Scope / Source / Diff as Tools tabs. Each tab is memoised on the data it shows so the registry only updates when that changes.
