Properties#

badge?

optional badge?: number | string | null

Defined in: ui/client/features/shell/types.ts:50

The little count next to the title. Three states, deliberately: undefined -- this tab never has one; null -- it has one whose value is not known yet; a value -- show it.

null exists because of #252. A tab fed by background work (Diagnostics by construct validate, Diff by a file changing on disk) has no badge until that work lands, and a badge appearing widens the tab and shoves every tab after it sideways -- out from under a pointer already reaching for one. Declaring the badge up front reserves its room, so the value can arrive whenever it likes without moving anything.
