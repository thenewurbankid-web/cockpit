API reference

AST API

Parse, walk, extract and edit TypeScript and JSX.

9 modules, 74 documented exports. Version next. All packages.

src/ast

  • extractAST package: extraction. Exports: extractExports, extractImports, extractJsdoc, lineOf, staticImportEntries
  • jsxEditAST package: deterministic text edits on JSX nodes located by parseJsxTree (#173). Exports: NEW_CHILD_SNIPPET, addChildText, removeAttributeText, removeNodeText, renderAttrValue, setAttributeText, setSpreadText, spliceNode, ...
  • jsxParseAST package: strict JSX parsing on typescript-estree (the JSX edit/analysis family, #173). Exports: checkJsxReplacement, jsxParseError, parseJsx
  • jsxScopeAST package: what a page component has in scope, and what a child component declares (#173). Exports: collectComponentScopeNames, collectScopeDeclarations, declaredPropNames, findImportOfName, findTypeMembers
  • jsxTreeAST package: the JSX element tree with stable node ids (#173). Exports: findParentRecord, jsxAttributes, jsxNameToString, parseJsxTree
  • parseAST package: parsing. Exports: parseToAst, parseTsSource
  • tsNodesAST package: TypeScript compiler API helpers -- searching a ts.SourceFile and printing `ts.factory` nodes back to source. Exports: findAllNodes, findNode, printNode
  • walkAST package: traversal. Exports: CONTROL_FLOW_TYPES, collectBareIdentifierUsages, collectCalls, collectControlFlowNodes, isNonUsagePosition, walkForUsage

src

  • astExports: addChildText, checkJsxReplacement, collectBareIdentifierUsages, collectCalls, collectComponentScopeNames, collectControlFlowNodes, collectScopeDeclarations, CONTROL_FLOW_TYPES, ...
