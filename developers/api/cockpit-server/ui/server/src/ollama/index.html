ui/server/src/ollama

Thin wrapper around Ollama's local HTTP API (default http://localhost:11434, overridable via OLLAMA_HOST for anyone running it on a non-default port/host).

Cockpit server, next. Source: ui/server/src/ollama.mjs.

startOllamaPull()#

startOllamaPull(name): Promise<any>

Defined in: ui/server/src/ollama.mjs:47

Starts a model pull and returns the raw fetch Response so the caller (the /api/ollama/pull route) can stream Ollama's own newline-delimited JSON progress events straight through to the browser as they arrive, instead of buffering a multi-GB download in memory. No timeout here — a real pull can legitimately run for many minutes.
