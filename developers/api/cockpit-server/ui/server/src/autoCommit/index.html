recordSave()#

recordSave(root, relPaths, opts?): any

Defined in: ui/server/src/autoCommit.mjs:177

Tell the auto-committer that the Cockpit just wrote a file. This is the single entry point every save route calls; it never throws for a non-git or non-project directory, because a save must succeed whether or not it can be committed.

Parameters#

root

string

project root

relPaths

string | string[]

opts?
kind?

Returns#

any

one of: {status:'disabled'|'not-a-repo'}, {status:'manual'|'coalescing', pending}, {status:'needs-decision', dirty}, or {committed:true, commit}.
