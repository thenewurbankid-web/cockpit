runFeatureTests()#

runFeatureTests(root, feature, opts?): Promise<any>

Defined in: src/engine/testRunner.mjs:333

Run a feature's tests (all of them, or the one name/area names) against the app at baseUrl.

Options: name, area ('generated'|'yours'), baseUrl, signal (AbortSignal), timeoutMs, onProgress(line), and the test seams probe, tmp, repo. Resolves (never rejects) to {ok:true, feature, baseUrl, durationMs, counts, tests, traces} (traces: relative paths of kept failure traces, see keepTraces) or {ok:false, error:{code, message}}. Nothing is written inside the project.

Parameters#

root

string

Project root.

feature

string

Feature whose tests run.

opts?

any = {}

See above.

Returns#

Promise<any>

{ok:true, feature, baseUrl, durationMs, counts, tests, traces} or {ok:false, error}; never rejects.

Example#

const run = await runFeatureTests(root, 'billing', { baseUrl: 'http://localhost:3000', area: 'generated' });
