pickSourceFrame(frames): any

toProjectPath()#

toProjectPath(input, context): string

Defined in: src/engine/previewFiber.mjs:470

Containment: turn whatever the page said into a path RELATIVE to the project root, or null. Nothing the previewed app sends can make the Cockpit name a file outside the open project — this is the block's most important property.

context.servedFrom is the project-relative directory the dev server serves from (a Vite root, a Next app in a monorepo package); URL-shaped references are resolved under it.

Parameters#
