generateFeatureTests()#

generateFeatureTests(root, feature, options?): any

Defined in: src/engine/testGenerator.mjs:277

Generate (or refresh) a feature's locked specs. Everything is validated before anything is written. The generator is the ONLY writer allowed into the frozen tests/generated/ region: it writes with fs directly after its own checks (fs.mjs's write() refuses the frozen glob for everyone else). Returns { written, unchanged, orphans, pruned, skipped, truncated }.

Parameters#

root

string

Project root.

feature

string

Feature whose specs are generated.

options?

dryRun writes nothing, prune deletes orphaned specs, max caps the number of specs.

dryRun?

boolean = false

max?

number

prune?

boolean = false

Returns#

any

{written, unchanged, orphans, pruned, skipped, truncated}: what happened to each spec (file names).

Example#

generateFeatureTests(root, 'billing', { dryRun: true });
