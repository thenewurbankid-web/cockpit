commit()

commit(opts?): object

Validate the buffered result in an isolated shadow copy of root, then either:

  • commit: replay every staged write onto the real root (via src/fs.mjs's write()) and clear the buffer, or
  • abort: leave root completely untouched. Either way the shadow copy itself is always cleaned up.
