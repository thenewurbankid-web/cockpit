fillGeneratedFile()#

fillGeneratedFile(root, file, layer, options?): Promise<any>

Defined in: src/generators.mjs:357

Overwrite one already-generated file's stub content with llm's real implementation. root is only used to build the file's prompt-relative path (for the same reason import.mjs's fill does — a clearer prompt, not a behavior difference); file must already exist (i.e. call this after generateLayer/generateVertical, never instead of it). llmOptions is passed straight through to callLlm — see llm.mjs's ollama provider for what it can carry (model/baseUrl). Returns { file, status: 'filled'|'rejected'|'failed', reason?, attempts } — see llm-fill.mjs; anything but 'filled' leaves the stub untouched.
