extractImports()#

extractImports(source): string[]

Defined in: src/ast/extract.mjs:66

Module specifiers referenced by static or dynamic import, e.g. import x from 'y' or import('y'), in source-position order. AST-based: walks real ImportDeclaration nodes plus ImportExpression (dynamic import(...)) nodes anywhere in the tree, so a specifier-shaped string sitting inside a comment or a string literal is never mistaken for a real import (the #74 false-positive class).

Parameters#

source

string

Source text.

Returns#

string[]

Import specifiers, static and dynamic, in source order.

Since#

0.8

Example#

extractImports("import a from './a'; const b = import('./b');"); // => ['./a', './b']

resolveRelativeImport()#

resolveRelativeImport(fromAbsFile, importPath): any

Defined in: src/architecture-enforcer.mjs:274

Resolve a relative import specifier from fromAbsFile to an absolute file on disk, trying the bare path plus the usual extension/index fallbacks. Returns null for an external/bare specifier, or if nothing on disk matches any candidate — the caller decides what that means (unclassifiable vs. IMPORT-001's "this doesn't exist yet").
